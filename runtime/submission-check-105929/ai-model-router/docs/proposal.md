# 第25题选题方案

目标：把不同任务分配到合适的大模型，返回可解释选型、真实答案、用量与费用估算，并能被Agent Runtime当作技能调用。

核心场景为简单问答、材料摘要、代码与复杂推理。输入长度和用户偏好修正档位；路由自身不调用大模型，以减少Token。使用真实开源LiteLLM SDK统一访问DeepSeek，按两个模型的三个参数档位组织能力。

交付统一SKILL.md与Python Script、网页Demo、可重复测试与十条验收样例、报告、视频、Runtime加载证据和Windows操作指南。密钥通过本地动态设置，默认不随仓库分发。生产功能要求有效Key、网络与余额。

验收指标：三类任务正确分档、真实回答非空、服务返回usage、缓存重复零新增调用、输入异常可解释、密钥不回显不提交、nanobot能发现Skill并执行脚本。测试不以小样本声称模型质量领先。
