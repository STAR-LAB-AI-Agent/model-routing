## 常见答辩

- 为什么不让另一个模型来做路由？规则成本低、可解释，避免额外调用；代价是语义识别有限，后续可用标注集评估。
- LiteLLM用在哪里？providers.py的completion是唯一生成边界，实际向DeepSeek提交messages和模型参数。
- 三档是否三个模型？不是，Flash一个、Pro一个；Pro有关闭和开启思考两档。
- Token是否估算？预览中的输入预算是字符估算；生成后的输入/输出来自usage。
- 费用是否等于账单？按公开峰谷和供应商输入缓存价格估算，以服务商账单为准；不含nanobot编排模型。
- 如何证明真实调用？响应含真实model、usage、finish_reason；提供独立评估、录屏同批JSON及完整nanobot运行记录。
- 为什么CLI重复不能缓存？每次启动新进程，缓存只驻留内存；网页同一服务进程可复用。
- Key变化要重启吗？不用，下一次请求读取新配置，并隔离旧缓存。
