# 从这里开始

1. 双击 start-demo.bat，浏览器打开 http://127.0.0.1:8765 。
2. 右上角“API 配置”可以保存、更换或测试 DeepSeek 密钥。当前电脑已配置；提交包不携带个人密钥，换电脑要重新输入。
3. 依次选择简单问答、摘要整理、代码推理，点击“发送并执行”。每次会调用真实模型并计费。
4. 再次执行同一任务，观察缓存命中与新增费用为 0。
5. 现场完整操作见 docs/acceptance-guide.md。
6. 提交 deliverables/实验报告.pdf、demo.mp4 与代码仓库。先填 docs/student-info.json，再重建 PDF。

API 密钥在页面密码框输入，不要贴到 GitHub、报告或录屏。
